# CPGE PSI Hub
`npm i && npm run dev`. Put files in `public/storage/<subject>/<FOLDER>/` (subjects: math, physique, chimie, informatique, si, cat; folders: COURS TD EXERCICES DS SUMMARIES CNC CF). If that tree is empty, `data/resources.json` (run `npm run seed` to regenerate) is used. Name CNC files like `CNC 2023 - Phys 1.pdf` and `CNC 2023 - Phys 1 - Corrigé.pdf`.
